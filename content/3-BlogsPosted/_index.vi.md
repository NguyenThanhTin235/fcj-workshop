### [Blog 1 - XÂY DỰNG AI AGENT CÓ BỘ NHỚ DÀI HẠN VÀ CHẠY CODE SANDBOX VỚI AMAZON BEDROCK AGENTCORE](3.1-blog1/)

Bài viết giới thiệu giải pháp xây dựng AI Data Assistant thông minh bằng cách kết hợp Amazon Bedrock AgentCore Memory (bộ nhớ dài hạn) và Code Interpreter (môi trường sandbox thực thi code an toàn). Giúp Agent vừa duy trì bối cảnh, ghi nhớ sở thích và quy tắc phân tích của người dùng qua nhiều phiên tương tác, vừa có khả năng chạy code Python để tính toán và trực quan hóa dữ liệu chính xác thay vì chỉ dự đoán kết quả.

### [Blog 2 - AMAZON TEXTRACT – VƯỢT XA VIỆC TRÍCH XUẤT VĂN BẢN TỪ TÀI LIỆU](3.2-blog2/)

Bài viết phân tích giải pháp xử lý tài liệu thông minh (Intelligent Document Processing - IDP) với dịch vụ Amazon Textract trong dự án hệ thống tuyển dụng. So sánh sự vượt trội của Textract so với OCR truyền thống thông qua khả năng bóc tách cặp khóa - giá trị (Key-Value), bảo toàn cấu trúc bảng biểu, truy vấn thông tin theo câu hỏi tự nhiên (Queries), nhận diện chữ ký, cùng các lưu ý về độ tin cậy (Confidence Score) và tối ưu hóa chi phí vận hành.
