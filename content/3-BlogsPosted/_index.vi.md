### [Blog 1 - XÂY DỰNG AI AGENT CÓ BỘ NHỚ DÀI HẠN VÀ CHẠY CODE SANDBOX VỚI AMAZON BEDROCK AGENTCORE](3.1-blog1/)

So sánh sự vượt trội của Textract so với OCR truyền thống thông qua khả năng bóc tách cặp khóa - giá trị, bảo toàn cấu trúc bảng biểu, truy vấn thông tin theo câu hỏi tự nhiên, nhận diện chữ ký, cùng các lưu ý về độ tin cậy và tối ưu hóa chi phí vận hành.

### [Blog 3 - AWS CODEBUILD KẾT HỢP CODEPIPELINE – TÌM HIỂU CÁCH XÂY DỰNG CI/CD PIPELINE TRÊN AWS](3.3-blog3/)

Bài viết chia sẻ cách xây dựng quy trình CI/CD tự động hóa trên AWS thông qua việc kết hợp AWS CodePipeline và AWS CodeBuild. Tìm hiểu cấu trúc file `buildspec.yml`, cơ chế trao đổi dữ liệu qua Artifacts trên Amazon S3, kịch bản tích hợp cùng GitHub, Amazon ECR và Amazon ECS, cùng các lưu ý quan trọng về phân quyền IAM, quản lý Secrets và tối ưu hóa hiệu năng build.
