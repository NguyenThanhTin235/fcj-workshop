During my internship, I participated in technical events, each providing a memorable experience with fresh, exciting, and rewarding knowledge, along with wonderful moments.

### [Event 1 - First Cloud AI Journey Meet Up](4.1-event1/)

* **Event Name:** First Cloud AI Journey Meet Up
* **Organized Date & Time:** 09:00 - 12:00, 24/10/2026
* **Location:** 26th Floor, Bitexco Financial Tower, 02 Hai Trieu, Ben Nghe Ward, District 1, Ho Chi Minh City
* **Role in Event:** Attendee
* **Main Content & Activities:** A technical meet up featuring 5 in-depth sessions on Cloud and AI Agents delivered by enterprise Tech Leads and engineers (low-latency Vietnamese Voice AI at ~1.8s, secure multi-account resource sharing via AWS RAM and SCPs, automated infrastructure pentesting with Security Agents, production AI Agent deployment using Amazon Bedrock AgentCore on EC2 Spot MicroVMs, and Kiro Crew 24/7 AI Agent operations).
* **Results Achieved:** Acquired production-grade AI Agent architectures, cloud cost reduction techniques via MicroVMs and EC2 Spot, context window governance, shift-left CI/CD security practices, and expanded professional networks with AWS industry experts.
